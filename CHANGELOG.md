## 0.1.0 — 2026-10-08

Primera versión local preparada de License Activation Guide.

### Skill

- Guía independiente del lenguaje para arquitectura, reglas comerciales, firmas, activación online/offline, cupos, LAN y recuperación.
- Referencia condicional de Rust/Windows con separación entre política y adaptadores.
- Revisión con Security Regression Guard: autorización por acción, relaciones entre clientes/licencias/equipos, cachés, trabajos pendientes, consumo e importación.
- Modos diferenciados para auditoría, implementación, diagnóstico y revisión de cambios.
- Patrones y escenarios genéricos sin publicar el protocolo ni detalles operativos del proyecto privado de origen.

### Repositorio

- Carpeta instalable autocontenida con licencia y avisos de autoría y responsabilidad.
- README en español e inglés, portadas SVG y referencias bajo demanda.

- Documentos de contribución, reportes sensibles, publicación y versionado.
- Plantillas de GitHub y escenarios sintéticos bilingües.
- Ocho pruebas de mantenimiento del paquete; no equivalen a pruebas de una implementación de licenciamiento.
